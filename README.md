# Modern C++ Course (Coursera / Packt)

Hi everyone! 👋

This is my repository for the [Complete Modern C++ (C++11/14/17)](https://www.coursera.org/specializations/packt-complete-modern-c-plus-plus)
specialization by Packt on Coursera. I will be uploading all my notes, exercises,
activities and anything else interesting I come across while doing the course.

So please, feel free to take this information, use it and review it however you like.

## What's inside

The specialization is made up of three courses, and this repository follows the same structure.
The notes live right next to the code: each folder has its own `README.md`, so you can read
everything straight from GitHub.

| # | Course | Topics |
|---|--------|--------|
| 1 | [Foundations of Modern C++](01-foundations/) | Types, initialization, control flow, pointers, memory, functions, file I/O |
| 2 | [Advanced Object-Oriented & Generic Programming](02-advanced-oop/) | Classes, operator overloading, inheritance, exceptions, templates, the STL |
| 3 | [Modern C++ Features & Concurrency](03-features-concurrency/) | Move semantics, smart pointers, lambdas, C++17 features, concurrency |

Every example is a standalone file, so you can compile any of them on their own:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic example.cpp -o example
./example
```
